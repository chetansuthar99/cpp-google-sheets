# Chetan Portfolio Pro (CPP)

Chetan Portfolio Pro is an easy-to-use investment portfolio application designed for Indian investors.

## Platform

- Google Sheets
- Google Apps Script
- TypeScript
- GitHub

## Version

v0.1.0-alpha

## Core Objective

Simple, fast and intelligent portfolio management.

## Version 1.0 Scope

- Indian Stocks (NSE & BSE)
- ETFs
- Mutual Funds
- Portfolio management
- Buy/Sell transactions
- Portfolio performance
- Buy/Hold/Reduce/Sell signals
- Investment scanner
- Portfolio health
- Reports

## Development Principle

CPP prioritizes ease of use, reliability and maintainability over unnecessary feature complexity.
